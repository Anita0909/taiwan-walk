# 台灣走走 Taiwan Walk

AI 課程作業：先建立中文 AGENTS.md，再依規則製作可持續擴充的台灣景點知識庫。

## 收錄景點
- 新北：野柳地質公園——自然地景。
- 南投：車埕貯木池——產業文化。
- 台南：井仔腳瓦盤鹽田——產業文化、歷史文化。
- 花蓮：石梯坪——自然地景。
- 澎湖：大菓葉柱狀玄武岩——自然地景。
- 馬祖：芹壁聚落——歷史文化。

## 擴充指令範例
「請先閱讀 AGENTS.md，再依 templates/place.md 新增一篇景點文章。查證官方來源，更新來源筆記、索引、網站與異動紀錄，最後說明實際完成的檢查。」

## 內容結構
- `AGENTS.md`：AI 協作與資料查證規則。
- `templates/`：景點文章模板。
- `wiki/places/`：景點文章。
- `wiki/sources/`：來源筆記與查證限制。
- `wiki/index.md`：依地區與類型瀏覽的索引。
- `wiki/log.md`：內容異動紀錄。

## 資料使用
文章以不同發布單位的可信公開資料交叉整理，文末附具名來源。僅呈現已確認資訊；查證限制保留於來源筆記。時間、費用及交通可能變動，出發前請確認官方最新公告。

## 瀏覽與更新
開啟 `docs/index.html` 可在本機瀏覽網站。首頁支援圖集左右滑動、箭頭切換、關鍵字搜尋與地區篩選。

修改 `wiki/` 的文章後，執行 `python build.py`，即可同步產生 `docs/` 網頁與 `dist/` 發布檔案。使用 GitHub Pages 時，發布來源選擇分支中的 `/docs` 資料夾。

## 照片
照片作者、來源、授權與拍攝日期記錄於 `photos.json` 及網站「圖片出處」頁。照片為歷年實景，採原作或來源提供的縮小版本，不調色或變更畫面內容；首頁與卡片採版面裁切顯示。照片授權獨立於專案程式碼，使用時須保留各照片署名與授權。
