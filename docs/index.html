About this collection

風景有故事，
知識有出處。

台灣走走是一個持續累積的旅遊知識庫，以官方來源整理景點的地景、文化與參觀資訊。每篇都保留來源和查核日期，讓下一次探索有跡可循。

以政府觀光網站、景點官網及營運單位資料交叉整理。時間與費用可能變動；照片為歷年實景，不能代表當日狀態。
